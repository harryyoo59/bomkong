# 부모 로그인 (이메일+비밀번호) — 사장님 한 번만

소설가처럼 **같은 화면에서 바로** 가입·접속합니다.
메일 링크는 쓰지 않아요. 구글·애플은 당분간 안 켭니다.

## 꼭 맞춰 줄 것 (한 번)

메일 확인을 끄지 않으면, 가입 후에도 바로 안 들어올 수 있어요.

1. [이메일 로그인 설정](https://supabase.com/dashboard/project/gjqekmpapsqozahabytt/auth/providers) 열기
2. **Email** 누르기
3. **Confirm email** (메일로 확인받기) 를 **끄기**
4. 저장

## 쓰는 방법

1. 거실 → **로그인**
2. **가입하기**: 이메일 + 비밀번호(6자 이상) + 확인 → 가입
3. 다음부터는 **접속하기**: 이메일 + 비밀번호

성공하면 거실 왼쪽이 **부모 나가기**로 바뀝니다.

