# 관리자실 비밀글 넣는 방법

거실 오른쪽 「관리자실」 문을 누르면 **관리자 입장** 화면이 나와요.
손님 메뉴와 섞이지 않고, 비밀글은 **인터넷 서버에서만** 확인해요.

## 사장님이 할 일 (인터넷에 올린 뒤)

1. 호스팅(예: Vercel) 설정 화면을 열어요.
2. **환경 변수(비밀 설정)**에 아래 이름을 추가해요.

```text
BOMKONG_ADMIN_SECRET
```

3. 값에는 **본인만 아는 긴 비밀글**을 넣어요.
4. 저장한 뒤 사이트를 다시 열어 「관리자실」 → 비밀글 입력으로 들어가요.

## 꼭 지킬 것

- 비밀값은 **저장소·화면에 올리지 마세요.**
- `.env.example`에는 이름만 있고 값은 비워 둡니다.
- 값이 없으면 입장 화면은 보이지만, 「아직 비밀글이 서버에 없어요」라고 안내하고 **통과는 안 됩니다.**

## 동작 요약

1. 문 클릭 → `/admin` (세션 확인)
2. 없으면 `/admin/login`에서 비밀글 입력
3. 서버가 환경 변수와 비교 → 쿠키로 입장 유지
4. 공부방: 규칙 / 캐릭터 / 로고 / 올리기

## 아직 없는 것

- 소셜 로그인 연동 (나중)
- 결제·재고·계정 (상품·구독은 상태 안내만)
