# 관리자실 열쇠 설정

손님용 메뉴와 관리자실은 섞이지 않습니다. 거실 오른쪽 문 「관리자실」만 공부방으로 이어집니다.

## 필요한 것

배포 환경(예: Vercel)에 **서버 전용** 환경 변수:

```text
BOMKONG_ADMIN_SECRET=여기에_긴_비밀값
```

- 저장소·화면·클라이언트 코드에 비밀번호를 넣지 마세요.
- `.env.example`에는 이름만 있고 값은 비워 둡니다.
- 값이 없으면 `/admin`은 로그인 화면의 「아직 열쇠 설정이 없어요」 안내로만 가고, 공개 우회는 없습니다.

## 동작

1. 문 클릭 → `/admin` (미들웨어가 세션 확인)
2. 없으면 `/admin/login`에서 열쇠 입력
3. 서버가 환경 변수와 비교 → HttpOnly 쿠키 세션
4. 공부방 가구: 규칙 / 캐릭터 / 로고 / 올리기

## 아직 없는 것

- Supabase·소셜 로그인 연동 (나중)
- 결제·재고·계정 (상품·구독은 상태 안내만, 가짜 결제 완료 없음)
